<p align="center">

  <i>Read and reply to kernel mailing lists.</i>
</p>

Koshi is a native GTK4 + libadwaita app for browsing, searching, and replying
to the mailing lists archived on [https://lore.kernel.org](https://lore.kernel.org).

## Building

```sh
cargo run -r
```

or

```sh
nix run
```
