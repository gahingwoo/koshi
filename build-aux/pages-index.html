Read and reply to kernel mailing lists.

This is the Flatpak repository for Koshi. Add the remote and install: 

flatpak remote-add --if-not-exists koshi https://dl.nikableh.moe/koshi.flatpakrepo
flatpak install koshi moe.nikableh.Koshi

Then run it, or launch Koshi from your applications menu:

flatpak run moe.nikableh.Koshi

Updates arrive through the usual flatpak update.

Prefer a one-off install without adding a remote? Download the .flatpak bundle from the latest release and install it: 

flatpak install koshi.flatpak
Signed with the repository's GPG key. Source and issues on GitHub.
